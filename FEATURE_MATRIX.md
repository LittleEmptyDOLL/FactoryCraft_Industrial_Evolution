# Feature matrix — 0.20.0

0.20.0 adds four full-size one-item poles, explicit persisted copper edges, manual/automatic wiring, whole-foundation square coverage, visible sagging wires, coverage overlays and pole status. Canonical names and optional Jade inspection now work through controllers and parts. See ELECTRICITY.md and VALIDATION.md for exact adaptations/evidence. Schema-4 ports and existing production kernels remain unchanged; old intermediate pole worlds require a fresh fixture.

**Implemented** refers only to the explicit scope in the row. **Partial** is not the entire requested subsystem. Evidence: VALIDATION.md. This release delivers stage 1 and a playable part of stage 2; stages 3–8 are not complete. Previous version 0.18.0 added blue/white independent wire colors and cached whole-splitter motor gates, preserving the existing transport kernel and legacy defaults. Stage 3 and later systems remain partial.
