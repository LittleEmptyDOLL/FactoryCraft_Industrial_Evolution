# Первая автоматическая фабрика — 0.6.1

Мир 0.6.0 можно продолжать. Для более старых компактных версий нужен новый мир. Крупные жилы ищите в новых чанках; диапазоны задаются в `config/factorycraft-worldgen.toml`.

1. Начальные ресурсы добудьте обычным способом Minecraft. Скрафтите генератор, столбы, бур, печь, сборочный автомат, ленты и четыре манипулятора. Рецепты открываются в книге после получения железного слитка.
2. Найдите крупную заводскую жилу железа/меди/угля/камня на поверхности. ПКМ покажет её запас. Ручная добыча даёт одну единицу, оставляя блок до истощения. Обычные ванильные руды бур не разрабатывает.
3. Поставьте бур 3×3 над залежью: он охватывает область 5×5 на глубину восьми блоков от нижнего центра. Выберите направление и центральный блок основания до установки; превью покажет весь занимаемый объём и препятствия.
4. Снабдите генератор углём через нижний слот. Столбы соединяются и покрывают **центры** машин в радиусе шести блоков (с учётом высоты); генератор выдаёт до 80 FE/т. Один уголь — 1600 питающих тактов при спросе.
5. Манипулятор забирает за собой, кладёт перед собой. Между внешними гранями двух машин нужен блок манипулятора. Все части машины ведут к единственному инвентарю контроллера. Входы — левые слоты, выходы — правые; генераторное топливо — нижний слот.
6. Разместите бур → манипулятор → две ленты → манипулятор → печь → манипулятор → сборочный автомат → манипулятор → сундук. Все передачи автоматические. Сборщик выбирает шестерни автоматически из железных пластин; в GUI можно закрепить рецепт.
7. Shift + ключ снимает всю машину с её запасами в одном предмете. Для поворота установите его заново. Ключ поворачивает обычные ленты и манипуляторы на месте.

## Проверенная схема

Координаты ниже — внутренние контроллеры проверенной командной схемы. При ручной установке 3×3 машины целитесь на один блок восточнее и южнее контроллера (в центр основания). Вид сверху; все контроллеры смотрят на север, крупные машины растут на восток и юг. Y — один общий уровень основания машин; залежь ниже на блок.

| Объект | Передний левый угол X,Z | Занимаемая площадь |
|---|---:|---:|
| Бур | 0,2 | X=0..2, Z=2..4 |
| Манипулятор → | 3,3 | 1×1 |
| Ленты → | 4,3 и 5,3 | по 1×1 |
| Манипулятор → | 6,3 | 1×1 |
| Печь | 7,2 | X=7..9, Z=2..4 |
| Манипулятор → | 10,3 | 1×1 |
| Сборщик | 11,2 | X=11..13, Z=2..4 |
| Манипулятор → | 14,3 | 1×1 |
| Сундук | 15,3 | 1×1 |
| Генератор | 5,7 | X=5..7, Z=7..9 |
| Столбы | 4,5; 9,5; 13,5 | по 1×1 |
| Залежь под буром | 1,3, Y−1 | запас по умолчанию 1000 |

Код этой схемы используется и `/factorycraft demo`, и серверным сквозным тестом. Команда требует свободную загруженную область 30×8×13 справа/впереди от игрока; полезно выполнять над плоской площадкой с воздухом вокруг. Она создаёт залежь, снабжает генератор углём и не кладёт руду, пластины или шестерни в машины. `/factorycraft smelter` строит такую же цепочку с ускоренной промышленной печью.

Другие примеры: `/factorycraft waterworks`, `/factorycraft steamworks`, `/factorycraft oilworks`. Они также проверяют область 30×8×13 и используют настоящие полные структуры. Диагностика: `/factorycraft power`, `/factorycraft fluids`, `/factorycraft profile`.

Сохраните и закройте мир, затем загрузите: положение лент, инвентари, запас залежи, прогресс, FE и идентичность частей должны сохраниться.
