# EMI / JEI — 0.9.0

Оба просмотрщика необязательны. Без них остаются собственные меню машин, требований рецептов и исследований. Клиентские точки входа изолированы; выделенный сервер работает без классов EMI/JEI.

Проверяемые версии для **Minecraft 1.21.1 / NeoForge**:

* EMI **1.1.24+1.21.1**.
* JEI **19.70.0.469** (его Maven-зависимость MezzConfig 0.6.10).

Категории содержат актуальные рецепты из клиентского RecipeManager: плавка/сборка, химия со всеми тремя выходами НПЗ, кипячение и исследования. Показаны машины-катализаторы, альтернативные ингредиенты и точные количества, жидкости с native components, время/FE и стоимость единицы науки/число единиц. Присутствие рецепта в просмотрщике не отменяет серверные исследования. Автоматический перенос рецепта/ингредиентов в машину пока не реализован.

Для ручной проверки из исходников:

```sh
./gradlew runClient -PrecipeViewer=jei
./gradlew runClient -PrecipeViewer=emi
./gradlew runGameTestServer -PwithViewers=true
python tools/download_optional_mods.py build/optional-runtime
./gradlew runGameTestServer -PwithViewers=true -PftbModsDir=build/optional-runtime
```

`recipeViewer=both` или `withViewers=true` включает оба. При совместной установке EMI выбирает свой интерфейс/JEI bridge согласно настройкам просмотрщиков; их общие предупреждения о повторяющихся ванильных tag-рецептах не являются дублированием предметов фабрики. Для чистой проверки интерфейса используйте один просмотрщик. Новые JAR-зависимости не включаются в FactoryCraft и не коммитятся; загрузчик тестовых FTB-зависимостей проверяет закреплённые SHA-256 официальных файлов.

Плагины отображают рецепты, а не выполняют их. Они не имеют доступа к серверному списанию предметов/жидкостей, исследованиям или FE. Оригинальные processing/boiling/chemistry форматы сохранены; research имеет собственный ограниченный codec. См. RESEARCH.md и VALIDATION.md.
